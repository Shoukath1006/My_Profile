    GET /principles
    
      
    How I approach the work.
    
      
    
        
    Get the numbers right
    Billing, tax, discounts and refunds are where small mistakes cost real money, so calculation logic gets validation and careful handling of edge cases.
    
        
    Fix the query first
    Slow endpoints usually start in the data layer. I look at the SQL and the data handling before reaching for a cache.
    
        
    Keep modules small and clear
    Clean, modular service layers make code easier to review, test and change, especially for whoever maintains it next.
    
        
    Stay with it in production
    A feature is finished when it runs reliably. I handle deployments and database changes and work closely with QA and frontend teams.
