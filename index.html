About

From the database to the app store.

I'm a full-stack and mobile developer with over three years of experience. I design Spring Boot services and REST APIs, build the web screens on top of them, and develop the Android and iOS apps people use every day.

The systems I work on tend to have rules that must come out right. A water bill, an insurance split on a care invoice and a refund on a tour booking all need to be correct every time, so I care about clean service layers and consistent data.

    Approach
    
            
    How I approach the work.
    
            
    
                
    Get the numbers right
    
                    
    Billing, tax, discounts and refunds are where small mistakes cost real money, so calculation
                        logic gets validation and careful handling of edge cases.
    
                
    Fix the query first
    
                    
    Slow endpoints usually start in the data layer. I look at the SQL and the data handling before
                        reaching for a cache.
    
                
    Keep modules small and clear
    
                    
    Clean, modular service layers make code easier to review, test and change, especially for whoever
                        maintains it next.
    
                
    Stay with it in production
    
                    
    A feature is finished when it runs reliably for users. I handle builds, releases, deployments and
                        database changes, and work closely with QA.
